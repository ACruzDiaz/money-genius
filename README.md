MoneyGenius is your smart calculator designed to measure your potential and inspire you to reach the next level. With a simple yet powerful algorithm, it can estimate your future income and motivate you to achieve your financial goals.




⚠️ Factors the model does not capture:

- Gender and ethnicity (documented wage penalties)
- Migration status 
- Physical and mental health
- Hierarchical position within organizations
- Structural discrimination

Contributions are welcome! Please read the [CONTRIBUTING.md](CONTRIBUTING.md) file for more information.






## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
